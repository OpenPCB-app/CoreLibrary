# openpcb-core-library

Readable JSON source for the OpenPCB Core Library — the default set of
symbols, footprints, 3D models, and components shipped with the OpenPCB
desktop app.

## Layout

```
symbols/<category>/<name>.symbol.json
footprints/<category>/<name>.fp.json
3d/<category>/<name>.glb
3d/<category>/<name>.model.json     (optional sidecar metadata)
components/<category>/<name>.component.json
schemas/                             JSON Schema (draft 2020-12)
tools/validate.ts                    schema + cross-reference validator
tools/pack.ts                        builds .opclib release artifact
library.json                         generated by `bun pack`
```

## Commands

```sh
bun install
bun validate                  # validates the source tree
bun pack --version 1.0.0      # writes openpcb-core-library-1.0.0.opclib
bun admin                     # local browse + edit + import web UI
bun test                      # runs all package tests
```

## Admin viewer

`bun admin` launches a local web UI on `127.0.0.1:5173` (backend `:7173`) that
supports browse / edit / KiCad import / template generation / pack from the
browser. See `apps/admin/README.md` for details.

## ID convention

`openpcb.core.<category>.<slug>` — dotted, lowercase. Examples:

- `openpcb.core.passive.resistor`
- `openpcb.core.footprint.passive.r-0603`
- `openpcb.core.symbol.passive.resistor`
- `openpcb.core.3d.passive.r-0603`
